Expense Tracker

Overview

Expense Tracker is a Python mini project that helps users record and manage their daily expenses.

Features

- Add expenses
- View all expenses
- Calculate total spending
- Store expense data in a text file

Technologies Used

- Python 3
- File Handling

How to Run

1. Open "expense_tracker.py" in Python IDLE.
2. Press F5 to run the program.
3. Select options from the menu.

Project Structure

- "expense_tracker.py" - Main program
- "expenses.txt" - Stores expense records
